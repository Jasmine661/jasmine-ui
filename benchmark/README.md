# Jasmine UI 性能测试

这个目录包含了 Jasmine UI 组件库的性能测试代码。

## 🚀 使用方法

### 运行性能测试

```bash
# 运行所有组件的性能测试
node benchmark/performance-test.mjs
```

## 📊 测试内容

测试覆盖了所有 12 个组件的多种配置：

- **Button**: 8 种不同配置
- **Alert**: 6 种不同类型
- **Input**: 8 种不同配置
- **Menu**: 4 种不同模式
- **Tabs**: 4 种不同配置
- **Progress**: 8 种不同状态
- **Upload**: 4 种不同配置
- **AutoComplete**: 4 种不同配置
- **Icon**: 6 种不同配置
- **Form**: 3 种不同配置
- **Transition**: 6 种不同动画
- **Welcome**: 4 种不同配置

## 📈 性能指标

测试会显示以下性能指标：

- **平均渲染时间**: 每个组件的平均渲染时间（毫秒）
- **每秒操作数**: 每秒能渲染多少次组件（ops/sec）

## 🔧 依赖要求

确保已安装以下依赖：

```bash
npm install benchmark @testing-library/react jsdom
```

## 📝 注意事项

1. 性能测试结果会因运行环境而异（CPU、内存等）
2. 建议在相同的环境下进行对比测试
3. 测试结果仅供参考，实际性能可能因使用场景而异
4. **重要**: 此测试代码不会被包含在 npm 包中，仅用于开发环境

## 🎯 性能目标

- 简单组件：> 1000 ops/sec
- 复杂组件：> 500 ops/sec
- 所有组件：< 5ms 渲染时间
